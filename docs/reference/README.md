# منابع فهرست محاسباتی

`فهرست-۲۰۵۰-عنوان-محاسباتی-برق-قدرت.pdf` فایل PDF مرجعی است که برای این پروژه ارائه شده است.

`formula-list-2050.txt` نسخه متنی UTF-8 نرمال‌شده برای ابزار `tools/gen_data.py` است. هر بخش ۵۰ عنوان پایه دارد و مجموع آن ۴۱ بخش و ۲۰۵۰ عنوان است. فایل متنی صرفاً برای تولید ساختار داده برنامه است؛ برای مشاهده صفحه‌بندی و متن اصلی به PDF مراجعه کنید.
