# فرمول‌های برق صنعتی (اندروید، آفلاین)

اپ اندروید برای ۲۰۵۰ عنوان محاسباتی برق قدرت. جستجو، ۴۱ موضوع، ماشین‌حساب زنده برای هر عنوان، سه حالت DC / تک‌فاز / سه‌فاز، ورودی با ارقام فارسی، بدون نیاز به اینترنت.

## گرفتن APK (بدون نصب Android Studio)
1. در گیت‌هاب یک مخزن جدید بسازید و همه‌ی فایل‌های این پوشه را در شاخه‌ی `main` آپلود کنید (پوشه‌ی `.github` هم باید باشد).
2. تب **Actions** ← workflow به نام **Build APK** (خودکار اجرا می‌شود؛ یا Run workflow بزنید).
3. بعد از چند دقیقه، همان صفحه ← بخش **Artifacts** ← `electrical-formulas-apk` را دانلود کنید و APK داخلش را نصب کنید.

## ساختار
- `app/src/main/assets/` : خود برنامه (HTML/JS). `calcs.js` فرمول‌ها، `data.js` فهرست ۲۰۵۰ عنوان.
- `app/src/main/java/.../MainActivity.java` : پوسته‌ی WebView، فقط فایل‌های داخلی را باز می‌کند و دسترسی اینترنت ندارد.
- `COVERAGE.csv` : وضعیت تک‌تک ۲۰۵۰ عنوان.
- `tools/gen_data.py` : ساخت دوباره‌ی `data.js` و `COVERAGE.csv` از فایل فهرست.
- `tools/test_calcs.js` : تست خودکار (`node tools/test_calcs.js`).

## واقعیت درباره‌ی ۲۰۵۰ فرمول
فایل فهرست خودش می‌گوید عنوان‌ها همه فرمول مستقل نیستند: ۵۰ فرمول پایه × ۴۱ موضوع = ۲۰۵۰ عنوان.
پس در برنامه ۵۰ ماشین‌حساب پایه وجود دارد که برای هر موضوع با سیستم مناسب (DC/تک‌فاز/سه‌فاز) تنظیم می‌شود.
وضعیت هر عنوان:
- **مرتبط:** فرمول پایه همان چیزی است که عنوان می‌خواهد.
- **عمومی:** فرمول عمومی درست است، ولی روش تخصصی آن موضوع (مثلاً IEC 60909، IEEE 80، تحلیل هارمونیک) پیاده‌سازی نشده.
- **نامرتبط:** عنوان برای آن موضوع معنای مستقیم ندارد (مثل «سرعت سنکرون در خطوط انتقال»).

این دسته‌بندی را من با قواعد دستی ساخته‌ام و تقریبی است. نتایج برای طراحی واقعی باید با استاندارد و دیتاشیت سازنده کنترل شوند.
