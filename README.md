# ماشین‌حساب و مرجع مهندسی برق قدرت (Android)

اپلیکیشن آفلاین اندروید بر پایه فهرست PDF پیوست‌شده، با **۲۰۵۰ عنوان مرجع در ۴۱ موضوع**. عنوان‌های هم‌فرمول در محاسبه‌گرهای مشترک ادغام شده‌اند تا برنامه برای یک رابطه یکسان چند صفحه تکراری نسازد.

- ۳۳ خانواده فرمول پایه یکپارچه‌شده از ۵۰ الگوی پایه
- ۶۴ محاسبه‌گر تخصصی یکتا
- جست‌وجو با نام فرمول، موضوع و شماره عنوان PDF
- مسیر مستقیم از هر یک از ۲۰۵۰ شماره مرجع به محاسبه‌گر مربوط
- انتخاب سیستم DC، AC تک‌فاز و AC سه‌فاز در محاسبه‌گرهای مرتبط
- پشتیبانی از ارقام فارسی و عربی در ورودی‌ها
- محاسبه آفلاین؛ برنامه برای کارکرد عادی به اینترنت نیاز ندارد

> **توضیح شمارش:** خود PDF تصریح می‌کند که ۲۰۵۰ عنوان لزوماً ۲۰۵۰ فرمول مستقل نیستند؛ بسیاری از عنوان‌ها کاربرد یک رابطه پایه در تجهیز یا شرایط کاری متفاوت‌اند. به همین دلیل، شمار عنوان‌های مرجع از شمار خانواده‌های محاسباتی مستقل جدا نگه داشته شده است.

## دریافت APK از GitHub Actions

برای ساخت APK نیازی به نصب Android Studio روی رایانه نیست:

1. فایل ZIP پروژه را استخراج کنید.
2. محتوای پوشه `ElectricalCalc` را در ریشه یک مخزن GitHub قرار دهید؛ پوشه مخفی `.github` را هم حتماً نگه دارید.
3. مخزن را روی شاخه `main` پوش کنید. Workflow با هر Push یا Pull Request به `main`/`master` اجرا می‌شود؛ اجرای دستی هم از مسیر **Actions → Build APK → Run workflow** ممکن است.
4. پس از موفقیت اجرا، وارد همان اجرای Workflow شوید و از بخش **Artifacts** فایل `electrical-formulas-apk` را دریافت کنید.
5. فایل `app-debug.apk` را روی دستگاه اندرویدی نصب کنید. فایل `.sha256` همراه APK برای بررسی یکپارچگی دانلود است.

این Workflow نسخه **Debug** را می‌سازد که با کلید Debug امضا شده است. انتشار عمومی در Google Play به پیکربندی جداگانه کلید امضای Release نیاز دارد؛ هیچ کلید خصوصی یا رمز امضایی داخل این مخزن قرار داده نشده است.

### ارسال پروژه با Git

پس از استخراج ZIP و باز کردن ترمینال در ریشه پوشه پروژه:

```bash
git init -b main
git add .
git commit -m "Initial ElectricalCalc Android project"
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

`USERNAME` و `REPOSITORY` را با نام حساب و مخزن خودتان جایگزین کنید.

## ساختار مخزن

```text
ElectricalCalc/
├── .github/workflows/build-apk.yml   # تست فرمول‌ها و ساخت APK
├── app/                              # پروژه اندروید و فایل‌های رابط کاربری
│   └── src/main/
│       ├── assets/                   # HTML، CSS، داده‌ها و منطق محاسبات
│       ├── java/                     # پوسته Android WebView
│       └── res/                      # آیکون و منابع اندروید
├── docs/reference/                   # PDF اصلی و فهرست UTF-8 قابل بازتولید
├── tools/gen_data.py                 # تولید data.js و COVERAGE.csv
├── tools/test_calcs.js               # تست خودکار محاسبات
├── COVERAGE.csv                      # وضعیت ۲۰۵۰ عنوان مرجع
├── build.gradle.kts
└── settings.gradle.kts
```

## ادغام فرمول‌های تکراری

هرگاه چند عنوان یک رابطه یا روش محاسباتی یکسان داشته باشند، یک صفحه مشترک دارند و حالت ورودی/خروجی از داخل همان صفحه انتخاب می‌شود. نمونه‌ها:

- قانون اهم و محاسبه معکوس ولتاژ، جریان و مقاومت
- امپدانس، اندازه، زاویه فاز و ضریب توان
- مثلث توان و محاسبه هم‌زمان P، Q، S و ضریب توان
- افت ولتاژ و درصد افت ولتاژ
- مقاومت هادی و تصحیح دمایی آن
- تلفات اهمی و مسی
- فرکانس، دوره تناوب و سرعت زاویه‌ای
- سرعت سنکرون و لغزش
- توان، راندمان و جریان
- ضرایب هم‌زمانی و تنوع
- ضرایب بارگذاری، بهره‌برداری و تقاضا
- چگالی جریان و انتخاب سطح مقطع هادی
- محاسبه خطا/نسبت CT و VT در یک محاسبه‌گر

شماره‌های مرجع PDF حذف نشده‌اند. جست‌وجوی شماره یا انتخاب عنوان از فهرست موضوعی کاربر را به صفحه محاسبه‌گر مشترک هدایت می‌کند؛ بنابراین قابلیت ردیابی عنوان‌های اصلی حفظ می‌شود. مدل‌های فیزیکی متفاوت، صرفاً به‌دلیل شباهت ظاهری نام، با هم ادغام نشده‌اند.

## منبع فهرست ۲۰۵۰ عنوان

- `docs/reference/فهرست-۲۰۵۰-عنوان-محاسباتی-برق-قدرت.pdf` نسخه PDF ارائه‌شده به‌عنوان مبنای پروژه است.
- `docs/reference/formula-list-2050.txt` نسخه متنی UTF-8 نرمال‌شده همان فهرست است که ابزار تولید داده از آن استفاده می‌کند.

برای بازتولید فهرست برنامه از ریشه مخزن اجرا کنید:

```bash
python tools/gen_data.py docs/reference/formula-list-2050.txt
```

این دستور `app/src/main/assets/data.js` و `COVERAGE.csv` را بازتولید می‌کند. اجرای موفق آن باید هر ۲۰۵۰ عنوان و ۴۱ موضوع را شناسایی کند.

## تست محاسبات

Node.js نسخه ۲۰ یا جدیدتر لازم است:

```bash
node tools/test_calcs.js
```

تست‌ها خروجی پیش‌فرض همه ۲۰۵۰ عنوان، مقادیر مرجع عددی، خانواده‌های یکپارچه و لینک محاسبه‌گرهای تخصصی را بررسی می‌کنند.

## پیش‌نیازهای ساخت محلی APK

- JDK 17
- Android SDK Platform 34 و Build Tools 34.0.0
- Gradle 8.7

```bash
gradle :app:assembleDebug --no-daemon
```

خروجی در مسیر زیر ساخته می‌شود:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## محدودیت و ملاحظات مهندسی

فهرست PDF یک فهرست عنوان/سناریوی محاسباتی است، نه کتابچه فرمول و نه مرجع طراحی استاندارد. برچسب پوشش در `COVERAGE.csv` نشان می‌دهد یک رابطه پایه تا چه اندازه با عنوان مرتبط است؛ این برچسب جایگزین تأیید مهندسی نیست. محاسبات تخصصی باید با استاندارد مربوط، شرایط شبکه، ضرایب اصلاحی، مشخصات سازنده و مقررات محل پروژه کنترل شوند. خروجی برنامه به‌تنهایی تأییدیه طراحی یا ایمنی تجهیزات نیست.
